# Zura Beridze — Developer Portfolio

Personal portfolio of Zura Beridze, a web developer and IT specialist based in Tbilisi, Georgia.

- **Projects** — selected websites and web applications, with descriptions, screenshots, and the technologies behind them.
- **About** — professional experience, education, and technical skills.
- **My Story** — the path from IT support and technical work to web development.
- **Contact** — a way to get in touch about projects and collaboration.

The site adapts to mobile and desktop screens and offers light and dark themes with a choice of accent colors.

Built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.
